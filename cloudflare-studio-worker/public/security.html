Private Studio

Security boundary

This page documents the intended security boundary for Studio.AutumnNails.com. It is a build-time reference only and is not a login page.

Current state: isolated GitHub branch only. No production DNS, Cloudflare Access application, authentication policy, secrets, or deployment has been changed.

Authentication target

  1. Cloudflare Access protects the entire Studio hostname before the application is reached.
  2. Approved email address signs in using Cloudflare's one-time six-digit email PIN.
  3. Independent MFA then requires a TOTP authenticator code.
  4. Only after both factors succeed does Cloudflare allow access to Studio.

Application boundary

  • The Studio frontend must not contain the old admin password.
  • The old production /admin/ session remains untouched until the replacement has been tested.
  • Studio API access will be migrated deliberately rather than exposing the existing admin bearer-token endpoints directly.
  • No credentials, OTP secrets or TOTP setup keys belong in Git.

This document is deliberately static and contains no authentication logic or secrets.
